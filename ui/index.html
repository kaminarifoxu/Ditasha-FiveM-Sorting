Pratinjau resource



Mulai menyusun resource
01
Impor file, folder, atau ZIP
Kategori dideteksi dari nama file GTA. Aset yang belum dikenal bisa kamu tentukan kategorinya melalui pilihan di tabel.
02
Pilih mode yang sesuai
Pertahankan / replace: nama file, YMT, dan META bawaan tetap utuh. Pakai untuk pack yang sudah jadi atau aset replace.
Add-on freemode: membuat YMT biner RSC7 dan shop META dari komponen YDD/YTD. Nomor drawable tiap komponen harus berurutan dari 000. Tekstur harus dimulai dari a. Angka dan nama tekstur internal tidak diubah.
03
Periksa lalu ekspor
Hasil ZIP berisi resource, fxmanifest.lua, aset, serta laporan pemeriksaan. Model dan tekstur pasangan berada dalam satu folder item, misalnya stream/hair/freemode/hair_000/. Nama file tetap utuh. Ekstrak ke folder resources FiveM, lalu tambahkan baris ensure dari README ke server.cfg.
Batas generator YMT
Generator berbasis nama file untuk komponen freemode GTA V Legacy. Ia tidak membaca rig atau mesh, tidak menghasilkan skeleton ped kustom, dan tidak membuat metadata props. Ped kustom membutuhkan YMT dan peds.meta asli. Aset escrow harus disertakan dengan seluruh berkas resource aslinya melalui alat lain.
Hasil generator perlu diuji di server FiveM sebelum dipakai. Total aset hingga 25 GB (25 × 1024³ byte). File dibaca bertahap; ZIP/ZIP64 diekstrak saat ekspor. Aplikasi desktop menulis ZIP bertahap langsung ke lokasi penyimpanan yang kamu pilih. Sediakan ruang disk untuk hasil ZIP; arsip keluaran dapat sedikit lebih besar dari total aset. Muat ulang halaman akan menghapus sesi impor.
Dokumentasi manifest Cfx.re · Referensi format CodeWalker


DITASHA Asset Sorter
Versi 1.4.0 · Windows x64 · Portable
Impor file/folder atau ZIP hingga 25 GB, susun folder per item, buat fxmanifest dan metadata YMT freemode, lalu lihat model YDD dengan pilihan tekstur YTD.
Aplikasi berjalan offline dan tidak mengunggah aset. Saat ekspor, pilih lokasi ZIP di perangkat. Ekspor hasil sebelum menutup aplikasi; sesi impor tidak tersimpan.
Preview 3D mendukung GTA V Legacy dan maks. 128 MB per file. Hasil YMT baru tetap perlu diuji di server FiveM.
